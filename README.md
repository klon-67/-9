# 🧙 Академія Магії

**Академія Магії** — це пригодницька гра з графічним інтерфейсом, створена на **Python** за допомогою бібліотеки **Tkinter**.

Гравець виступає в ролі молодого мага, який досліджує карту, збирає золото, відкриває скарби та б'ється з небезпечними монстрами. ⚔️

---

## 🎯 Мета гри

Головна мета — стати найсильнішим магом Академії.

Для цього потрібно:

* 🗺️ досліджувати карту;
* 👹 перемагати монстрів;
* 💰 збирати золото;
* 🎁 знаходити скарби;
* ✨ отримувати досвід;
* ⭐ підвищувати рівень;
* ⚔️ покращувати силу персонажа;
* 🧪 використовувати зілля;
* 🛒 купувати предмети в магазині.

---

## 🎮 Як грати

Після запуску гри персонаж з'являється на карті.

Для пересування використовуй:

```text
W      ↑
A  ←   ↓  →   D
```

Також можна використовувати **стрілки на клавіатурі**.

На карті можна зустріти монстрів, монети та скарби.

---

## 🧙 Персонаж

У грі персонаж має декілька характеристик:

| Характеристика | Опис                        |
| -------------- | --------------------------- |
| ❤️ HP          | Здоров'я персонажа          |
| 💙 Мана        | Магічна енергія             |
| ⭐ Рівень       | Поточний рівень             |
| ✨ Досвід       | Досвід для наступного рівня |
| 💰 Золото      | Ігрова валюта               |
| ⚔️ Сила        | Кількість шкоди ворогам     |

---

## ⚔️ Бойова система

На карті знаходяться вороги.

У грі є три типи монстрів:

### 👹 Гоблін

Має середню кількість здоров'я та приносить золото після перемоги.

### 🟢 Слайм

Слабший ворог, якого легше перемогти.

### 💀 Скелет

Сильніший ворог із більшою кількістю здоров'я та шкоди.

Коли гравець намагається перейти на клітинку з монстром, починається бій.

За перемогу можна отримати:

* 💰 золото;
* ✨ досвід.

---

## ❤️ Здоров'я

Гравець починає гру зі:

```text
❤️ HP: 100 / 100
```

Монстри можуть атакувати персонажа.

Якщо HP стане рівним `0`, гра закінчиться.

З'явиться повідомлення:

```text
💀 GAME OVER 💀
```

---

## 🧪 Зілля

У грі є два види зіль.

### 🧪 Зілля HP

Відновлює здоров'я персонажа.

Кнопка:

```text
🧪 Використати HP
```

### 🔵 Зілля мани

Відновлює магічну енергію.

Кнопка:

```text
🔵 Використати ману
```

---

## 💰 Золото

Золото можна отримувати за:

* 👹 перемогу над монстрами;
* 💰 збір монет;
* 🎁 відкриття скарбів.

Золото використовується в магазині.

---

## 🎁 Скарби

На карті можна знайти скрині.

Після відкриття скарбу можна отримати випадкову нагороду:

* 💰 золото;
* 🧪 зілля HP;
* 🔵 зілля мани.

Тому кожна гра може проходити по-різному.

---

## 🛒 Магазин

У грі є магазин.

У ньому можна придбати:

### 🧪 Зілля HP

**Ціна:** 30 золота.

### 🔵 Зілля мани

**Ціна:** 35 золота.

### ⚔️ Покращення сили

**Ціна:** 100 золота.

Після покращення сила персонажа збільшується.

---

## ⭐ Система рівнів

За перемогу над монстрами гравець отримує досвід.

Коли досвіду достатньо, персонаж переходить на новий рівень.

При підвищенні рівня:

* ⭐ збільшується рівень;
* ⚔️ збільшується сила;
* ❤️ здоров'я відновлюється;
* 💙 мана відновлюється.

---

## 🗺️ Карта

Карта створюється випадково під час запуску гри.

На ній можуть знаходитися:

* 🧙 гравець;
* 👹 монстри;
* 💰 монети;
* 🎁 скарби;
* 🧱 стіни;
* 🌳 вільні території.

Тому при новому запуску розташування об'єктів може змінюватися.

---

## 🎮 Керування

| Клавіша | Дія        |
| ------- | ---------- |

| `A`     | Рух вліво  |

| `D`     | Рух вправо |
| `↑`     | Рух вгору  |
| `←`     | Рух вліво  |
| `↓`     | Рух вниз   |
| `→`     | Рух вправо |
